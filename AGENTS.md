# AGENTS.md

This repository packages a portable 3D modeling skill for FDM printed parts. It turns a plain-language commission, reference photos, and measurements into verified, print-ready model artifacts through role-specific agents and deterministic checks.

* Inspect existing code, tests, contracts, and conventions before changing anything.
* Implement the smallest correct change; avoid unrelated refactors or added complexity.
* Add or update tests for success paths, edge cases, regressions, and failure modes.
* Run formatting, linting, type checks, unit tests, integration tests, and build checks.
* Review the diff with seperate review agents for correctness, compatibility, dead code, and hidden regressions.
* Do not finish until all checks pass and remaining risks or unverified assumptions are documented.
