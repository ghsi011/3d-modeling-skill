# oneplus-case-x2d-asa — the request

Diagnose a Bambu Studio export of a phone case with a card drawer, sliced for
ASA. The body was damaged somewhere in its own history.

What is asked: find the geometry, name the defects, and do not call the file
usable. Two objects are in the archive and only one of them is broken, so a
report that condemns the whole archive is as wrong as one that clears it.

`evidence_class: PARSER_SPECIMEN`. The heavier sibling of this file carries
4,892 boundary edges and is deliberately left out of the L0 set; this one is the
smaller defect count and the cheaper read.
